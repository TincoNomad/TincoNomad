### 🤹 About

I write code with the same curiosity that once lifted me through the air on a circus trapeze. Crossing Latin America by bike, performing in circuses, co-creating sustainable projects — my path has always been about connecting people, ideas, and systems.

Today that curiosity lives in **Rust**. I build backend systems meant to be reliable, efficient, and built to last — not just to ship.

I'm actively exploring **decentralized technologies** — Web3, Avalanche, and (soon) IPFS — because I care about infrastructure that empowers communities instead of extracting from them.

I still reach for **Python** when it's the right tool — scraping, LangChain automations — mostly as a bridge while I build the Rust-native version of the same idea.

> Engineering is the "how". I care just as much about the "why" — and who the system serves.
